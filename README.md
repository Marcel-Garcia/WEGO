# WEGO
WEGO is a SharePoint, Power Apps, Power Automate, and Power BI solution developed for INOVYN to manage and monitor R&D projects throughout their lifecycle. It provides a centralized platform for project data, financial reporting, documentation, and portfolio analysis, enabling teams to collaborate efficiently and maintain a single source of truth for innovation projects. The solution automates data collection, approval processes, document management, and reporting, while offering interactive dashboards to support strategic decision-making and project tracking. WEGO 3.0 further enhances the user experience by allowing direct data management through Power Apps, reducing reliance on Excel-based processes and improving data quality and visibility across the business.
